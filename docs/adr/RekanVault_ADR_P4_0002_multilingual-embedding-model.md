### RV-DEC-P4-0002 — Embedding model selection: BAAI/bge-m3 for English, Indonesian, and Javanese

- Phase: P4
- Status: Approved
- Owner: Sigit
- Date: 2026-08-06
- Decision required by: Phase P4 vector indexing and semantic retrieval pipeline
- Context: RekanVault pilot documents and queries require multilingual embedding support across English, Indonesian, and Javanese (Jawa), matching team communication and historical archives.
- Options:
  1. Use BAAI/bge-m3 (dense 1024-dim, multi-linguality supporting 100+ languages including EN, ID, JV).
  2. Use smaller monolingual/bilingual candidate (e.g. paraphrase-multilingual-MiniLM-L12-v2).
- Chosen option: Option 1 — `BAAI/bge-m3`.
- Why: Provides comprehensive coverage for English, Indonesian, and Javanese, supporting dense semantic search, sparse lexical weights, and multi-vector capabilities within a single model.
- Impact: Vector collection in Qdrant will use 1024-dimensional dense vectors generated by `BAAI/bge-m3`.
- Reversal trigger: If CPU embedding generation latency on worker tasks exceeds target SLA per document chunk.
- Related ADR/tests: RV-DEC-0011, P4-T5 (multilingual semantic retrieval tests).
